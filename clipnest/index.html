What it does

Your clipboard, with a memory.

A fast clipboard manager for Windows. Clipboard history, search, snippets, folders, pins, images, quick paste with Ctrl+Alt+V and optional encryption.

Search everything you copied

Full-text search across your whole history with highlighted matches, and filters for today, 3 days, this week or 30 days. That thing you copied last Tuesday is three letters away.

Quick paste, anywhere

Ctrl Alt V opens a little window over any app. Type, press Enter, and it's pasted where you were.

Snippets

Save text you type again and again, with keywords and placeholders like {date} and {clipboard}.

Pins and folders

Keep the clips that matter. Pinned clips and clips in folders are never cleaned up.

Text and pictures

Every kind of clip gets its own preview: links, colours, code with line numbers, file paths, images.

Private by default

Passwords, API keys and card numbers are spotted and skipped. Optional encryption for the rest.

Install

Up and running in a minute.

ClipNest comes as a standard Windows installer. Here's the one extra click you'll need.

  1. Download the installerClick the button to get ClipNest_1.0.0_x64-setup.exe.
  2. Get past SmartScreenThe installer isn't code-signed yet, so Windows may say it “protected your PC”. Click More info, then Run anyway.
  3. Install and goFollow the installer. ClipNest lands in your Start menu, and you can pin it to the taskbar.

What you need

  • Windows 10 or 11, 64-bit
  • Microsoft Edge WebView2 (already on Windows 11; the installer adds it on 10 if needed)
  • About 15 MB free space
