What it does

A sorting machine you build yourself.

An intelligent file organiser for Windows with a visual rule builder, preview before applying, undo, duplicate finder, bulk rename and schedules.

Build rules by dragging blocks

Conditions like Type, Name or Age, actions like Move, Rename or Trash. Drag them onto rule cards and watch each rule count the files it catches, live.

Preview everything

See every move grouped by destination, untick what should stay, then apply.

Undo anything

Every run is journalled. One click puts every file back, and removes the folders it made.

Duplicate finder

Finds identical files by their contents, keeps the original, and sets the copies aside.

Bulk rename

Patterns, counters, find and replace with regex, and a live diff of every new name.

On autopilot

Tidy as files arrive (it waits for downloads to finish), every few hours, or daily.

Install

Up and running in a minute.

Sortify comes as a standard Windows installer. Here's the one extra click you'll need.

  1. Download the installerClick the button to get Sortify-1.0.0-x64.exe.
  2. Get past SmartScreenThe installer isn't code-signed yet, so Windows may say it “protected your PC”. Click More info, then Run anyway.
  3. Install and goFollow the installer. Sortify lands in your Start menu, and you can pin it to the taskbar.

What you need

  • Windows 10 or 11, 64-bit
  • About 400 MB free space
  • Works fully offline
